# Использовать security level 0 для локального доступа

LED Matrix является домашним устройством, и владелец считает пароль onboarding AP и отдельную авторизацию WebUI лишним UX-трением. Домашняя сеть и AP устройства считаются доверенными: AP работает без WPA-пароля, WebUI и локальный `/api/*` доступны без admin password, session cookie и CSRF. Это решение заменяет локальные access-control требования ADR 0001 и тикетов T01/T04; `Security level 0` — каноническое название этой модели.

## Последствия

- Любой клиент в домашней сети или подключившийся к AP может читать diagnostics, менять настройки, запускать Bambu onboarding/logout/refresh, перезагружать устройство и инициировать Web OTA.
- Проект осознанно не защищается от недоверенного клиента внутри LAN/AP; это принятый продуктовый риск, а не незавершённая security-задача.
- Bambu-пароль по-прежнему не сохраняется, access/refresh tokens не выдаются через API и Cloud TLS остаётся обязательным: это требования внешнего Bambu contract и ограничение случайной утечки, а не локальная авторизация пользователя.
- Signed app image, app-descriptor validation, два OTA-слота и boot guard сохраняются как защита целостности/восстановления устройства; подпись firmware не превращает WebUI в закрытый интерфейс.
