# LED Matrix

Контекст описывает устройство LED Matrix, которое показывает время, погоду и нормализованное состояние печати Bambu Lab, не управляя самой печатью.

## Language

**Устройство**:
Физическая LED-матрица с контроллером, локальным WebUI и собственным сохранённым состоянием.
_Avoid_: агент, дисплей

**Security level 0**:
Локальная модель доступа устройства: домашняя сеть и onboarding AP считаются доверенными, поэтому AP, WebUI и локальный API не требуют паролей или пользовательской сессии.
_Avoid_: onboarding password, admin password, WebUI authentication

**Cloud Mode**:
Обычный облачный режим принтера Bambu Lab, в котором сохраняются Bambu Cloud и Bambu Handy. Это обязательный режим эксплуатации проекта.
_Avoid_: LAN Mode, Developer Mode

**Состояние принтера**:
Нормализованный снимок доступности принтера, жизненного цикла печати, прогресса, задания, слоёв и оставшегося времени независимо от транспорта получения данных.
_Avoid_: MQTT payload, relay response

**Прямая облачная интеграция**:
Режим устройства, в котором оно само получает состояние принтера из Bambu Cloud без постоянно работающего внешнего процесса.
_Avoid_: LAN-интеграция, прямое подключение к принтеру

**Relay**:
Внешний процесс на роутере, который получает состояние принтера из Bambu Cloud и передаёт его устройству. После завершения миграции является только временным средством совместимости и отката.
_Avoid_: обязательная часть устройства, облако

**Первичная авторизация**:
Пользовательский сценарий во встроенном WebUI, который создаёт облачную сессию устройства и позволяет выбрать принтер.
_Avoid_: ручная установка токена, консольная настройка

**Облачная сессия**:
Сохранённое право устройства получать данные аккаунта и принтера из Bambu Cloud до выхода пользователя или отзыва доступа.
_Avoid_: пароль Bambu, постоянный логин

**Видимый оверлей печати**:
Последнее подтверждённое состояние печати, которое остаётся на матрице при кратковременной потере транспорта и снимается только после подтверждённого завершения жизненного цикла.
_Avoid_: MQTT-состояние, online-флаг
